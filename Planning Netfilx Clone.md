What is it?
A personalized Netfilx clone centered around my favorite shows and acitvities

What Problem?
Display a organize my favorite shows and movies and a short description of the plot and what I like about them

Who will use this application?

Just me. This only needs 1 user type. nothing too complex

Features
 -Choice of genres, user is able to pick from a list, the selection will filter the movie and shows by that genre.
-For each show or movie, it should have an image depicting it and a short description within a card
 -Hovering over the card highlights it, clicking on the card opens it in a larger popup, the full description is displayed here. 
 -The cards have a star button to select to symbolize a favorite within the list.
 -The card should have an area to input a timestamp or episode of where they left off

Pages/Views
-Main page shows list with ability to select genre to filter them
-Currently watching page shows only cards with a timestamp or episode populated
-Favorites page shows all cards that have been Favorited
